# 文档编写规则

- 文档只写必要信息，表达简洁，避免堆砌术语
- 全局文档只写全局共用内容；只涉及子项目的内容放入子项目的文档目录
- 一个 md 只写一个主题；内容多或含多个子主题时拆成目录
- 每个目录用 `index.md` 作索引：只列本目录 md 和直接子目录的 `index.md`，不列深层文档；开头可写一句不超过 100 字的概述；索引用无序列表，每项可附一句不超过 50 字的说明
- 同一内容只写一处；需复用时提取为独立文档并用链接引用
- 文档中绝对路径（`/*`）以项目根目录为起点，相对路径（`./*`、`../*`、`*`）以当前文件所在目录为起点
- 文档不写代码、SQL 等；需要引用实现时，用 `[链接](/server/src/lib.rs#my_function)` 指向实际代码
- 与具体代码强绑定的说明（如接口用法）写在代码注释中，不单独建文档
- 文档只描述当前事实；与事实不符即修正或删除，不保留历史
  - 正例：后端使用 Rust 实现
  - 反例：后端原本使用 Go，因性能不佳改为 Rust 实现
- 使用 mermaid 画图，禁止使用 ASCII 字符画
